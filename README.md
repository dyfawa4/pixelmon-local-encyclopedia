## 打开与分享

1. 将 ZIP **完整解压**到任意文件夹。
2. 双击 `index.html`，用 Edge、Chrome、Firefox 或 Safari 打开。
3. 分享时发送整个 ZIP，保留其中的数据、图片和来源文件。

日常使用不需要 Minecraft、Java、Python、Node.js、Android 应用或网络。不要只复制一个 HTML，也不要在压缩软件的临时预览中打开。收藏保存在当前浏览器；换浏览器、清除浏览数据或移动目录可能影响收藏。

所有页面、数据和图片均来自本地文件。只有主动点击来源网站链接才会访问互联网。

## 招式与特性

招式页依据属性变化配色，使用属性与分类图标，提供威力、命中、PP / 最大 PP、先制度、接触判定、简述、详细说明和完整参数。

打击面显示全部 18 属性，可选择目标双属性计算基础倍率。学习者以图片卡片展示，支持中文搜索、学习方式筛选、等级提示与继续显示更多。

## 完整资料索引

在玩法手册列表点击「完整资料索引」，或将地址末尾改为 `#sources`。这里提供原始文档检索、全文、JSON 全字段、Excel 全工作表浏览与下载入口。

APK 的全部 32,316 个 assets 资源，以及当前 Pixelmon 的全部 8,315 个数据 JSON，按原字节保留。可读文档还整理为离线页面；图片在本地图片目录，其他原件在 `reference/`。Android 内置玩法正文与咖喱、果汁、垂钓表格通过静态读取提取，没有执行 APK。

飞行道馆繁体 NPC 对话原件含一个多余引号。网页提供仅修正该引号的可读副本，同时保留完整原文和原件；旧繁体编码按 Big5 正确读取。这个辅助 NPC 文件不影响图鉴、招式、物品功能。

## 数值含义

| 字段 | 应怎样理解 |
| --- | --- |
| 基础捕获率 45 | 捕获公式参数，不能直接当作 45% |
| 精灵球倍率 ×1 | 基础倍率，条件型精灵球另看说明 |
| 普通捕获估算 | 不包含巢穴、Boss、暴击捕获或服务器自定义条件 |
| 生成相对权重 | 满足条件的候选项之间的权重，不是百分比 |
| 战利品池的百分比 | 不同抽取池的概率不能直接相加 |
| 努力值收益 | 击败获得的基础努力值，不是种族值 |
| 模型尺寸 | Minecraft 模型 / 碰撞尺寸，不是本传图鉴身高 |
| NPC 任务 | Pixelmon 内置任务，区别于 FTB Quests |
| 商店价格 | 应用参考值，区别于整合包自制金币系统 |

中文长篇说明、分类、图片和汇总来自手机版 1.0.3，其已有资源与文本已逐项保留。当前模组另外存在、手机版未提供说明的少量内部条目，只展示可核实数据并注明，不凭空写效果。

版本、计数及 SHA-256 见 `data/source-manifest.json`，逐文件清单在 `data/source-inventory.json`、`data/game-inventory.json`。

## 手机与 iOS

网页适配手机浏览器，不依赖 Android。iOS「文件」快速预览可能不执行脚本或不允许读取相邻数据文件。电脑上直接双击无需服务器；iPhone / iPad 可由同一局域网的电脑提供静态目录，再用 Safari 打开。

电脑安装 Python 后，在百科目录运行：

```sh
python -m http.server 8000 --bind 0.0.0.0
```

手机访问 `http://电脑的局域网IPv4地址:8000/`，双方在同一网络；用完按 Ctrl+C 停止。作者也可将完整目录部署到静态网站空间。

## 文件结构

```text
index.html                 离线打开入口
app.js / foods.js          导航、详情、配方与计算器
style.css / reading.css    桌面、手机、属性主题与阅读样式
assets/                    本地图片
data/catalog.js            检索索引
data/pokemon|moves|items/   主要详情
data/abilities|guides/      特性与玩法专题
data/sources/              完整资料页面
reference/                 原资料；供网页查阅和下载
README.md                  使用说明
```

采用普通 JavaScript 按需载入，以支持本地文件；没有 CDN、远程字体或在线图片依赖。保留 `reference/` 才能使用资料索引中的原件下载功能。

## 1.1.1 阅读与查询改进

- 专题表格可按显示的中文名称检索，包括物品、宝可梦、群系与属性；原英文标识仍可搜索。
- 修复旧版烧炼配方的字符串成品显示；带数字后缀的配方记录标为配方参考，避免被误认成新物品。
- 合成图下方增加中文材料清单、数量和成品，手机无需依赖鼠标悬停辨识材料；任选材料会明确标注。
- 修复正文首个换行消失及手机版无参数跳转标记，时间、天气和相关入口更易阅读。
- 繁殖材料标明三组均须提交；普通商店价格负字段改为“未记录”，不是负数金币。
- 觉醒力量表增加按六项个体值计算的属性列，原应用两列记录另标为参考。公式已核对当前模组实现；上方计算器同样按此计算。
- “旧世代转移招式”与 TM 世代加上含义说明；特殊伤害计算不再写成容易与变化类混淆的“变化”。
- 超极巨因子与当前形态能否超极巨化分开解释；条件球的估算明确未计入额外条件。
- 多花纹宝可梦从图片菜单选择花纹与异色；没有独立闪光图片的形态明确提示，避免按钮切换后仍显示普通图造成误解。

这些改动针对中文呈现与阅读方式，原始资料仍保留在本地资料索引中。
