# 智皮卡与智皮卡 Z · 1.4.4 详细玩法

本说明对应 2026-10-15 构建的重铸内容回迁 1.4.4。智皮卡是独立宝可梦，游戏内中文名为**戴帽子的皮卡丘**，英文名为 **Cap Pikachu**，种类参数为 `CapPikachu`，图鉴编号为本模组的 **1026**。

## 独立身份、能力与养成

普通皮卡丘与智皮卡是两个种类。普通皮卡丘携带智皮卡 Z 不会变成智皮卡，也不能使用本版专属的「雷之起源」。智皮卡**不能进化、不能培育，没有 Mega 或超极巨化进化分支**；普通皮卡丘原有进化规则保留。正常与闪光智皮卡各有 32×32 像素头像，队伍栏与旅行地图使用统一尺寸，保留已确认的戴帽 3D 模型。

| 项目 | 数值或规则 |
| --- | --- |
| 属性 | 电 |
| 性别 | 固定为公；旧存储的雌性独立智皮卡会校正，保留养成 |
| 特性 | 电气制造者（Electric Surge） |
| HP / 攻击 / 防御 | 135 / 65 / 120 |
| 特攻 / 特防 / 速度 | 175 / 100 / 125 |
| 种族值合计 | 720 |
| 自然刷新等级 | 70 |
| 原生捕获率参数 | 3，与巨金怪的原生参数相同 |

能力值仍按原生等级、性格或薄荷、IV、EV 等计算，种族值不等于摘要中最终能力值。电气制造者出场时展开的是**普通电气场地**；只有使出本版专属 Z 招式，才会展开**爆裂场地**。

升级兼容：1.3.0 的 `ash_cap` 是普通皮卡丘的携带物外观。1.4.4 校正时会还原为普通皮卡丘，保留其原种类和养成；不会免费转成新的独立智皮卡。原生其他戴帽形态也不因此自动成为 `CapPikachu`。

## 自然获取与捕捉

智皮卡只在 **`minecraft:plains` 平原生物群系内的真实村庄**生成。森林、沙漠、雪地、热带草原等其他群系的村庄不生成；玩家搭建的仿村庄也不等同于世界生成的村庄结构。最终生成位置需同时满足平原与村庄条件。原生极巨化与太晶巢穴均排除智皮卡，它不会通过巢穴自然生成。

它接入原生神兽刷新计时，不另开一套普通刷新计时。智皮卡对应的概率在原生配置概率上**减去40个百分点，下限为0**：

| 原生神兽刷新概率 | 智皮卡对应概率 |
| --- | --- |
| 100% | 60% |
| 70% | 30% |
| 50% | 10% |
| 40%及以下 | 0% |

神兽查询会分别显示全局概率、候选权重和智皮卡专属概率；全局70%时专属概率显示30%，候选权重100%不表示必定刷新。

这不是把原概率乘以60%。原生候选选择、位置可用性与刷新开关仍生效，70%→30%也不意味着每次计时都必定有30%的概率选中智皮卡这个种类。

**捕获率3不是固定3%的成功率。** 实际成功率由原生公式结合剩余HP、异常状态、精灵球效果等计算，属于极难捕捉的个体。大师球、公园球和起源球对智皮卡被禁止；普通合法球仍可尝试，爆裂场地不能解除禁止。管理员测试生成的巢穴个体也不能绕过这三种球的限制。

真正获得并存入同行队伍或 PC 后，可以完成挑战成就**「最好的伙伴」**；仅在野外生成或看见不算获得。

## 击败奖励

可正常产生战利品的野生智皮卡被实际击败后，原生战利品流程保证含**大师球1个与智皮卡Z1个**。保留其他原有奖励及领取流程；捕捉、逃跑、玩家自己的宝可梦或NPC队伍不发此奖励，原生禁止掉落的情况保持禁止。

## 技能池与配招

智皮卡继承实际安装版本的完整原生皮卡丘技能池，保留原有升级、回忆、教学与兼容学习器渠道，并追加以下七招到教学与第九世代学习器资格池：

| 新增招式 | 英文名 | 用途 |
| --- | --- | --- |
| 冥想 | Calm Mind | 强化特攻与特防 |
| 伏特替换 | Volt Switch | 电系进攻与换人 |
| 能量球 | Energy Ball | 草系补盲 |
| 真气弹 | Focus Blast | 格斗系补盲 |
| 诡计 | Nasty Plot | 强化特攻 |
| 过热 | Overheat | 火系补盲 |
| 精神强念 | Psychic | 超能力系补盲 |

新增学习资格不表示野生个体自动携带全部招式，也不突破四个招式槽。**「千万伏特」**追加为基础回忆招式，可通过技能回忆检查与学习。

例如「千万伏特＋伏特替换＋能量球＋冥想」兼顾专属 Z、换人、补盲与强化；也可按队伍需要替换为真气弹、过热或诡计。普通十万伏特与本版千万伏特是不同招式，不要把十万伏特当作雷之起源的转换前提。

## 智皮卡 Z 的合成与使用

将 **4个皮卡丘 Z** 无序合成为 **1个智皮卡 Z**。原料是 `pixelmon:pikanium_z`，成品是 `pixelmon:pikashunium_z`，可在工作台任意摆放四个原料；安装 JEI 后可查询标准配方。

1. 获得独立的智皮卡，并让它学会「千万伏特」。
2. 给智皮卡携带「智皮卡 Z」，玩家装备原生 Z 手环或满足原生对应资格。
3. 在允许 Z 招式的对战中，点击原生 Z 按钮，选择由「千万伏特」转换的**「雷之起源」**。
4. 遵守原生每方每场一次 Z 招式及战斗规则限制；携带晶石本身不会自动展开特殊场地。

| 招式 | 类型与类别 | 基础威力 | 命中数据 | PP |
| --- | --- | --- | --- | --- |
| 千万伏特 / Ten Million Volts | 电 / 特殊 | 120 | 100 | 基础5、最大8 |
| 雷之起源 / Origin of Thunder | 电 / 特殊 Z | 185 | 100 | 由原生 Z 流程使用 |

原生招式资格、目标、特性、免疫、PP与行动处理继续生效。名称统一为「雷之起源」，没有另保留一个「新星肃清」招式。

## 雷之起源：手下留情与全力攻击

**只有对可以正常投球捕捉的单个普通野生目标，雷之起源的直接伤害才会最多削减到1HP。** 已经是1HP的目标不会被这次直接伤害击倒，可接着使用合法球捕捉。

以下对战使用全力，允许正常击倒对手：玩家对战、NPC或馆主对战、原生极巨巢穴、太晶巢穴、Boss，以及不能投球捕捉的其他目标或阶段。不可捕捉标记、已有主人、禁止背包规则、同时存在多个可战斗的野生敌方目标等情况，也不套用手下留情。

手下留情只约束这招的直接伤害，不改变其他技能或毒、烧伤、反伤等后续伤害；这些效果仍可能使目标倒下。原生属性免疫也不会因为留1HP而被绕过。

## 爆裂场地的持续与属性效果

智皮卡使出专属 Z 招式后展开爆裂场地，播报为**「爆裂场地展开了！」**，右侧场地名称显示**「爆裂场地」**。

这是基于电气场地的特殊场地。**只要未被其他场地覆盖，就持续到本场战斗结束**，没有五回合倒计时。展开者换人或倒下不会凭空结束场地；战斗结束后不带入下一场。普通电气场地或其他场地覆盖后，特殊效果和黄色边框清除。

「展开方」指使出雷之起源的战斗一方，不只指智皮卡本人。额外属性效果如下：

- 展开方的**电属性宝可梦**使用**电属性攻击招式**时，对实际非中性属性倍率乘以 **1.25**。
- 对手攻击展开方的**电属性宝可梦**时，对实际非中性属性倍率乘以 **0.75**。
- **1倍中性倍率与0倍免疫保持原样**，沿用原生属性表。

| 情景 | 原生倍率 | 爆裂额外效果后的倍率 |
| --- | --- | --- |
| 展开方电属性宝可梦用电招打纯水系 | 2 | 2.5 |
| 展开方电属性宝可梦用电招打纯草系或纯电系 | 0.5 | 0.625 |
| 电招打地面系，且无其他原生免疫变更机制 | 0 | 0 |
| 电招打纯一般系 | 1 | 1 |
| 对手用地面招打展开方纯电系 | 2 | 1.5 |
| 对手用水招打展开方纯电系 | 1 | 1 |

表格只说明这项属性倍率调整，最终伤害还包含原生本系加成、电气场地、能力值、随机数及特性等。额外电系规则按实际电属性资格处理；原生电气场地的接地电招增益、睡眠防护与联动技能则继续遵守原生接地和招式条件，不能将所有效果混成一个固定伤害倍率。

## 爆裂场地的精灵球增益与黄色边框

展开方在本场对合法目标使用适用精灵球时，**在该球当时的原生有效捕捉倍率上加1**。例如1倍→2倍、2倍→3倍；不是最终捕捉成功率直接增加100%，也不改变智皮卡自身捕获率参数3。无效倍率、禁止球和原生限制保持有效。巢穴胜利捕捉阶段按本次团战与玩家资格衔接，不能跨场继承；太晶巢穴原有保证捕捉分支不需要额外提示。

黄色边框包裹受益技能的完整按钮与精灵球的图标、名称、数量区域。它提示当前场地效果资格，**不代表必中、一定克制或保证捕捉成功**。禁止球和当前无效球不获得提示。

提示不局限于智皮卡：队友能享受原生电气场地或爆裂电系效果时，符合资格的招式也会提示。太晶爆发按当前太晶状态的真实属性判定；觉醒力量、审判、多属性攻击、气象球、场地波动等变属性技能按实时招式条件处理。未太晶的一般属性太晶爆发不会被误标为电招，电太晶后的太晶爆发可按实际资格获得提示。

捕捉玩法可先以雷之起源展开场地并将可捕捉目标削到1HP，再使用带黄色提示的合法球；请同时留意异常与后续伤害，避免目标在投球前倒下。

## 修订2：捕捉限制提示

进入与野生戴帽子皮卡丘的战斗时提示：“该宝可梦无法用大师球、公园球和起源球捕捉！”。每位玩家每场只提示一次；普通皮卡丘和忍蛙不会触发。实际三种球的禁止捕捉规则继续有效。


## 1.4.4 获得成就修复

保持 1.4.3 的宝可梦玩法。真实获得个体后，无论进入同行队伍还是 PC 均检查物种成就；满队送入 PC 不再需要取出后补发。仅展示或客户端副本、未完成操作和未孵化的蛋不会计入。详细边界见 [成就检查记录](LEGENDARY_ADVANCEMENTS_1.4.4.md)。本版本游戏内验收尚待完成。


## 1.4.4 对战界面修复补充

修复 Z 招式边框预览丢失基础招式关联造成的空指针。黄色边框只提示爆裂场地实际作用，符合条件的队友普通招式继续显示；普通 Z 不显示黄边。智皮卡专属「雷之起源」也须满足当前场地条件。此次不改变服务端伤害倍率、场地持续、招式效果或捕捉规则。发布目前暂停，详见崩溃处理记录。
