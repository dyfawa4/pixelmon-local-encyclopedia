# 1.4.4 甲贺忍蛙：飞水手里剑强化与「殊途同归」

本次更新为已经完成牵绊进化的小智版甲贺忍蛙增加水系攻击增益，并增加取得牵绊进化特性个体的成就。普通甲贺忍蛙的飞水手里剑规则保持原样。任务书不作修改。

## 谁可以获得强化

使用者必须同时是甲贺忍蛙、小智形态，并保有 **牵绊进化（Battle Bond）特性**。原生小智形态 `ash` 和本模组首次成功牵绊进化后保存的常驻形态 `ash_permanent` 都适用。

只有牵绊进化特性、尚未变成小智形态的个体，普通激流／变幻自如个体，以及 Mega 甲贺忍蛙，均不因此获得这项小智形态增益。小智形态与 Mega 是两套独立玩法。

## 飞水手里剑的新效果

合格个体实际使出原生「飞水手里剑 / Water Shuriken」时，**先给自己赋予水系攻击威力 ×1.5 的临时增益，再结算本次攻击**。因此这次飞水手里剑立即受益，不需要等下一回合。

| 项目 | 普通甲贺忍蛙 | 符合条件的小智版甲贺忍蛙 |
| --- | --- | --- |
| 单次基础威力 | 原生15 | 保留原有20 |
| 攻击次数 | 原生2～5次，特殊特性按原生规则处理 | 保留固定3次 |
| 本次新增增益 | 无 | 自身水系攻击威力增加50% |
| 增益期间的飞水手里剑 | 无本次额外强化 | 每击按20 × 1.5 = 30计算，三击基础威力合计90 |
| 持续时间 | 无 | 三回合，包含使出当回合 |
| 重复使用 | 无本次额外强化 | 刷新三回合，不叠加倍率 |

这里的90是三击基础威力之和，**不是固定扣除90点HP**。最终伤害继续经过原生能力值、防御、本系加成、相性、命中和随机数等计算；整数取整会影响实际伤害。已有的原生攻击资格及多段攻击规则继续生效。

增益期间，使用者的**其他水系伤害招式也可受益**，按实际生效的招式属性判断。非水系招式和变化招式不获得这项攻击威力加成；队友及对手都不会共享增益。这不是改变场地，也不永久提高特攻面板或养成数值。查看／选择招式不会提前触发，Z招式不作为普通飞水手里剑启动此增益。

## 三回合怎么计时

- 第1回合使出飞水手里剑：先获得增益，当回合攻击即受益。
- 第2、3回合：增益保留，可用其他水系攻击。
- 第3回合结束：增益到期，在对战回合信息中播报水系强化结束。
- 若第2回合再次使出飞水手里剑：重新覆盖第2、3、4回合，第4回合结束到期；倍率始终是1.5，不会变为2.25。

开始强化时也会播报。换下时清除增益并播报结束；倒下或对战结束时清理临时状态。重新上场不会沿用此前剩余回合，需要再次使出合格招式。永久小智形态本身仍按既有规则保存，不会因增益结束消失。

中英文招式描述已经同步更新，原生技能学习、回忆、PP、先制度及动画渠道保持原样。

## 新成就「殊途同归」

玩家**实际获得并拥有牵绊进化特性的甲贺忍蛙**，真实存入同行队伍或PC后可完成。必须检查实际特性，其他特性无法完成；仅看见野生个体、NPC拥有该个体或只拥有相似外观不计入。已在自己的存储中的合格个体可通过已有存储补检取得进度。

成就不要求先变成小智形态；「取得牵绊特性个体」和「成功牵绊进化后使用强化招式」是两个阶段。它不自动解锁小智形态，也不修改任务书的目标、奖励或条件。
