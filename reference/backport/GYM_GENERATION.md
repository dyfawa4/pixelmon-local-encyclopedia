# 十八属性城市的自然生成地点

新增城市接入原生大城市生成器，沿用本体城市间距与地形适配。每次生成一个完整城市；已有存档需要探索未生成的区块。其他整合包的世界生成与本体结构设置可能影响出现频率。使用新增的 `/locategym <属性> [搜索半径]` 区分十八种属性，不再依靠共用的原生定位名称。

## 原有十类

| 属性 | 地点 | 群系标识或规则 |
| --- | --- | --- |
| 草 | 森林 | FOREST 类群系 |
| 火 | 下界荒地 | `minecraft:nether_wastes` |
| 幽灵 | 灵魂沙峡谷 | `minecraft:soul_sand_valley` |
| 妖精 | 桦木森林 | `minecraft:birch_forest` |
| 冰 | 积雪冻原 | `minecraft:snowy_tundra` |
| 电 | 热带草原高原、破碎热带草原 | `savanna_plateau`、`shattered_savanna`、`shattered_savanna_plateau` |
| 钢 | 热带草原 | `minecraft:savanna` |
| 龙 | 针叶林 | TAIGA 类群系 |
| 水 | 深海 | OCEAN 类且名称包含 deep 和 ocean |
| 地面 | 恶地 | MESA 类群系 |

原有规则保留；黑森林中的草系城市与新增恶系城市共同作为该区域候选。

## 按属性定位与探险家指针

- `/locategym 格斗` 或 `/locategym fighting`：查找当前位置维度的格斗主道馆。
- `/locategym 飞行 16384`：将半径扩大到 16384 格；默认 8192，允许 512–32768。
- `/locategym cancel`：取消当前搜索。命令需要管理员权限（等级 2）。结果中的坐标可点击填入传送命令；Y 使用当前位置高度，传送前请确认安全高度，创造模式检查更方便。

安装 Explorer’s Compass 1.16.5 后，搜索列表中有“一般属性道馆”“格斗属性道馆”等十八个中文入口，可直接输入属性筛选。已对整合包的修改版 `ExplorersCompassEdited-1.16.5-1.1.3-edited-forge` 做离线兼容检查。实际搜索读取原生结构起点，检查城市中的真实主道馆模板；住宅、馆主小组件及其他属性城市不会当作命中。黑森林候选池中的草/恶城市也按实际主道馆区分。指针使用命中的 X/Z 坐标；切换属性后旧搜索不会覆盖新结果。

搜索仍遵守当前维度、结构生成设置以及指针的最大半径、采样上限和黑名单。火与幽灵通常须前往下界；平坦预览地图用于观感验收，不能证明自然世界搜索成功。请在启用结构生成的自然世界中测试新区域。没有该可选模组时，回迁模组照常加载。

修改版指针与 Xaero 小地图的自动标记崩溃另做独立修复模组；该问题不属于本版道馆定位补丁，使用不兼容的小地图时可暂时关闭指针的自动新建标记选项。
