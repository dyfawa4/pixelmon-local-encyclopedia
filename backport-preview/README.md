## 安装

1. 使用 Minecraft 1.16.5、Forge 36.2.42 和 **Java 11**。已验证本体文件 `Pixelmon-1.16.5-9.1.13-universal.jar` 的内部版本为 9.1.12；其他版本未逐个验证。
2. 退出客户端和服务器，备份原存档及旧补丁。
3. 解压功能包，把 `mods/pixelmon-content-backport-1.16.5-1.0.0.jar` 放入实际游戏实例的 `mods`；替换旧补丁，只保留一份。保留原重铸本体，无需安装参考定制版。
4. 重新启动。多人游戏要求服务器及所有客户端使用相同补丁，不能混用旧网络协议版本。
5. 如需测试地图，按 [地图指南](TEST_MAPS.md) 安装独立地图包，不需要填写额外 JVM 参数。

回滚需要恢复更新前备份；写入新增物品／种类的存档不应直接在缺少本模组的环境中打开。

## 本版内容导航

- 小智甲贺忍蛙：从原生牵绊变身个体获取，真实对战触发后永久保持；强化水手里剑，保留换人、濒死、读档和电脑存取。Mega 甲贺忍蛙另走进化石与 Mega 手环规则。详见手册独立章节。
- 15 种新注册宝可梦（1011–1025），68 个种类的数据／形态补充条目：每个条目见 [手册](HANDBOOK.md)。普通与传说分别接入原刷新系统，缺少对应旧地形时使用明确列出的替代规则。
- 28 种对应宝可梦的 30 颗 Mega 石，包括雷丘 X/Y；快龙两个命名对应同一 Mega。每颗均有对应 Mega Boss 渠道。
- 69 个附加物品、8 张原生招式光盘、22 个招式定义，以及进化、面具、花蜜、多丽米亚美容、原生药品／薄荷／糖果／培育／钓鱼交互适配。
- 太晶珠配方、19 种属性与碎片、属性修改面板、战斗专用按钮、动态招式图标和克制显示、太乐巴戈斯／厄诡椪特殊分支。
- 独立太晶巢穴、约一半自然巢穴转换、300 秒团战、护盾、充能、捕捉及专属掉落；极巨巢穴保持原有掉落。引导线支持新巢穴与稀有宝可梦。
- 无极陨星高价配方与携带无极巨化、取下恢复；配方已修复对原生 NBT 大师球的识别，支持改名球。
- 原生创造栏「重铸内容回迁」共 77 项，巢穴放置器使用独立立体晶簇图标。
- 七张分工测试地图含配套队伍、所有 Mega 石、真实治疗仪和电脑、结束战斗控制、合成材料、培育屋与钓鱼池；06／07 重新进入保留测试进度。

## 规则与实现边界

所有新增获取、配方、50 级学习太晶爆发及旧版巢穴转换等适配规则，在手册中标明为**本模组新增规则**。本版本不声称完整迁移官方太晶或 ZA：统一晶体冠冕、太晶研究任务、训练家自动选择太晶、官方异步团战与完整欢呼尚未完成；三个资料不全的预览御三家仍禁用。完整规则、奖励权重与限制请阅读手册。

已通过 Java 11 构建、原生类转换、隔离 Forge 回归及本轮用户游戏内测试。接口检查和局部动态验收不代表每条联机／长期战斗分支都已人工覆盖；本次发布为正式版 1.0.0。
