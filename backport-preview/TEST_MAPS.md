# 重铸内容回迁 1.0.0 · 专用测试地图指南

七张地图单独分发，用于快速准备战斗、物品与原生交互场景。模组在普通存档中的生存渠道见 [完整手册](HANDBOOK.md)；地图免费物资与测试商店不代表生存规则。

## 下载与安装

1. 先安装正式功能包 `Pixelmon-Backport-1.0.0.zip`，使用 Minecraft 1.16.5、Forge 36.2.42、Java 11 和原有重铸本体。
2. 退出游戏，建议在整合包的独立副本中测试。
3. 解压 `Pixelmon-Backport-test-maps-1.0.0.zip`。把 `mods/backport-test-maps-1.16.5-1.0.0.jar` 放进这个实例的 `mods`，把 `saves` 下需要的地图文件夹复制到这个实例的 `saves`。**复制整张地图文件夹，不要把七张地图内容合并。**
4. 只保留一份地图控制模组；不要同时保留旧 `backport-client-test.jar` 或其他同 ID 的内部测试模组。地图控制模组仅为配套操作按钮和场景准备，不包含自动检查程序。
5. 启动客户端，单人游戏中选择名称以「回迁测试」开头的地图。第一次进入时自动搭建平台、准备队伍和物品；等平台与箱子完成再操作。无需额外 Java 启动参数。

地图采用自动搭建，因此存档第一次打开时与最终平台画面不同是正常的；安装了配套模组后会完成场景。若只看到普通平地、没有治疗仪或只有开局小火龙，优先检查地图配套模组是否安装、是否进入正确实例。不要更改存档内部的「回迁测试」名称前缀，识别依靠这个名称。

## 公共设施与操作

- 蓝绿色方块是场景控制台，**空手右键方块本体**，不是点击悬浮文字。不同控制台会准备队伍、开始战斗或改变测试状态，按文字选择。
- 物资放在木桶；治疗护士旁有真实治疗仪，另有电脑、工作台、铁砧与技能回忆师。太晶珠充能应使用真实治疗仪，不要仅对着护士点击后就判定充能失败。
- 队伍、随身物资、Mega 手环与测试资金由地图准备。ZA 场景含对应 Mega 石，所有新增石头也在物资桶内。
- 对战中无法走到结束控制台时，用聊天输入 **`/backportqa map end`**；这会结束当前测试对战。结束按钮不在战斗面板内。
- **`/backportqa map reset`** 重新准备队伍与随身道具，替换当前测试队伍，请先把想保留的个体存入电脑。06／07 的重置不会自动补回已经取走的木桶物资；需要全新物资可重新从原压缩包复制该地图。
- 01–05 每次重新进入会重新搭建并准备测试场景；06／07 已做进度保留，重进不会自动重置队伍、电脑、培育屋或木桶。
- 专用场景关闭日夜／天气循环与一般刷怪，侧重交互验证。**不能用地图内不刷野生精灵的现象判断正式生存刷新是否故障。**自然生成、传说间隔和 Boss 掉落应另用正常生存存档，按手册群系／时间／等级与原有刷新配置验证。

## 01：道具与宝可梦背包

1. 先在原生测试商人处买卖新增物品，检查中文名称、数量、价格结算、背包内对应物品。商店测试价格为 100，仅作地图测试。
2. 右键「背包内太晶珠与 52 水碎片」台。打开宝可梦背包确认太晶珠和碎片在里面；战斗外用太晶珠打开设置面板，把首位改为水。
3. 更改应消耗 50 枚对应碎片，剩 2 枚；不足 50、选择相同属性及特殊锁定属性不应错误扣除。
4. 右键「背包太晶实战」台，确认主背包中无需额外再放太晶珠也能识别；实际选择太晶后完成招式行动。对战使用会消耗充能，成功治疗后可再用。
5. 打开创造栏，翻页找到「重铸内容回迁」，检查 69 个物品加 8 张光盘、巢穴晶簇图标与太晶珠明显不同。

## 02：换形、技能回忆与 Mega

1. 「厄诡椪与面具」准备多只厄诡椪；从木桶取三种面具，放入匹配的携带槽，检查对应模型／属性及摘下恢复。太晶设置面板应提示面具属性锁定。
2. 「换形与物品进化队伍」用于花舞鸟花蜜、多丽米亚剪刀美容、铝钢龙复合金属、斯魔茶茶碗。把物品用在错误种类或错误茶碗形态上，应拒绝而不消耗。
3. 「小智甲贺忍蛙实战」会提供牵绊变身个体与剩 1 HP 的对手；用攻击击倒对手后检查小智形态。结束战斗、换人、濒死／复活、存取电脑或重进后应保留。只进战斗但没有触发条件，不能直接解锁。
4. 「ZA 新 Mega 队伍」提供已携带对应石头的队伍；场景还提供雷丘 X、雷丘 Y、快龙、宝石海星、甲贺忍蛙、完全体基格尔德和达克莱伊的独立战斗台。**点击写着「开始…战斗」的台会进入战斗，这是预期。**
5. 对战中使用原生 Mega 按钮；检查形态与结束恢复。Mega 甲贺忍蛙与常驻小智甲贺忍蛙是不同机制，不要混作一种形态。
6. 检查技能回忆列表中的名称与学习资格；需要更系统的等级、光盘、药品检查时使用 07。

## 03／04：太晶、Z、Mega 和招式显示

1. 03 选择水太晶、星晶、Mega／太晶、Z／太晶或太乐巴戈斯场景。
2. 检查专用太晶按钮与原有姓名、消息区域、Mega／Z 按钮在当前 GUI 缩放下不重叠。面板形状和尺寸仍受原重铸 GUI 缩放影响。
3. 在未太晶时太晶爆发图标为一般；完成水太晶后应为水图标。悬停检查招式类别、威力与克制显示是否随实际状态变化。
4. 切换 Mega、Z 和太晶选择，按服务端允许条件提交；不能通过重复点击重复太晶或同时获得互斥变形。
5. 04 检查双打下换人、选择相邻目标、晶光星群对应形态的作用范围，以及结束战斗后临时状态清理。
6. 用已耗充能的太晶珠再进战斗应受限制；通过治疗仪成功治疗后重新检查。可以把太晶珠放副手或宝可梦背包重复验证。

## 05：太晶巢穴和对照掉落

1. 先打左侧一星水太晶伊布，检查首领进入太晶而非极巨化；平台另有三星火太晶仆刀将军、六星电太晶快龙及普通极巨巢穴。
2. 观察 300 秒计时、招式充能、约 90 秒夺取充能与护盾触发；首领名字不应被状态条挡住。六星有明显难度，不要求一场就击败。
3. 胜利后检查同属性碎片固定数量、中文 TM171、随机星级奖励和捕捉界面。捕捉后检查太晶属性保留。
4. 普通极巨巢穴应仍极巨化并走原重铸掉落，不应被混入太晶碎片／专属 TM171 奖励。
5. 引导线应指向静止巢穴的实际位置，标明太晶信息；首领参战实体移动不能让巢穴本体跟着跑。
6. 蓝台「重新生成四个巢穴」可重建对照场景；不要在对战仍进行时重复生成，先结束对战。

## 06：无极陨星合成与无极巨化

左侧木桶有末地石砖、天界之笛、原生陨石和原生大师球；右侧木桶有成品对照及回复药。队伍首两只为 100 级普通无极汰那、勤奋性格、0 个体／0 努力值。

1. 在工作台将两侧六格放末地石砖，中间列自上而下放天界之笛、陨石、大师球，获得 1 个无极陨星。JEI 转移配方也应识别大师球。
2. 检查九格各消耗 1 个材料；改名大师球也有效，普通球、高级球、球盖或缺少球种标记的物品不能代替。
3. 手动把无极陨星放入无极汰那携带槽，检查无极巨化模型和能力；取下后恢复。勤奋／100 级／0 个体／0 努力值的无极巨化能力依次为 HP 620、攻击 235、防御 505、特攻 255、特防 505、速度 265。
4. 用当前首位战斗台进入真实战斗；结束、换场、电脑存取、重进后检查持有道具与形态是否一致。
5. 用「首位剩 1 HP」或「首位濒死」台，反复携带／取下不能免费治疗或复活；复活药和真实治疗仪应仍有效。
6. 把陨星给其他种类携带不能无极巨化。与原生「陨石」区分，不能把成品再作为原材料放配方中。

## 07：原生交互详细流程

物资包含全部药品、薄荷、经验糖果、新增物品和光盘、能力药／PP 道具、特性道具、培育材料／沙漏及四种鱼竿。右侧有钓鱼池，后方有原生培育屋与电脑。

### 等级与技能

选择「49 级升级与交互队伍」，首位铝钢桥龙带两个招式并留两个空位。喂神奇糖果升到 50，检查太晶爆发自动学习、中文名字与实际战斗效果；满四格时应走原生替换流程。技能回忆与 TM171 等光盘只对有学习资格的个体生效。

### 药品、薄荷、糖果与特性

用「损伤与灼伤／PP 耗尽」台准备伤势，再用回复药、解异常药及 PP 道具检查数值恢复与消耗；健康、无异常、PP 已满时再用应拒绝无效消耗。「首位濒死」台用于复活药。逐种薄荷检查能力变化、重复使用限制和原始性格保留；经验糖果及能力道具按等级／努力值等上限处理。特性胶囊与膏药受该种类普通／隐藏特性资格限制。

### 培育与孵化

「培育：铝钢桥龙与百变怪」提供：母体铝钢桥龙原始固执、内敛薄荷、不变之石，百变怪携带红线，双方满个体。放入原生培育屋并满足界面显示的原生要求／费用，可用沙漏推进。蛋应为基础种类铝钢龙，继承固执而不是内敛薄荷；红线至少继承五项满个体。队伍中太乐巴戈斯作为不可培育对照，不应凭空产蛋。取蛋与孵化走原重铸操作。

### 钓鱼

保留新宝可梦在队伍中，用原生鱼竿在池塘抛竿并等待正常咬钩，检查收竿／遭遇／捕捉。钓鱼池结果受普通鱼竿、群系、时间和原生池影响，并不保证钓出任意新增种类；重点验证新个体不会让正常钓鱼交互报错。

### 物品进化与御三家

「物品进化队伍」依次包含啃果虫、裹蜜虫、两个不同货色斯魔茶、铝钢龙和索财灵。分别使用蜜汁苹果、龙声鼓舞后升级、匹配茶碗、复合金属；索财灵身边准备 999 枚硬币后升级，检查正确扣除并进化。「帕底亚御三家队伍」用于既有草／火／水三家和第二阶段的原生升级与进化；资料不全的三个预览御三家不启用。

### 存取、换组与实际战斗

「更多回迁个体」按六只一组循环全部补丁种类，供你选择药品、光盘、技能回忆、存取电脑等检查。此按钮替换当前队伍，想保留个体先放电脑。使用「用当前首位战斗」测试现有携带道具与技能，不会重新发一只覆盖刚设置的首位。对手为只会跃起的幸福蛋，方便观察。06／07 退出重进后应保留你的队伍、物资消耗与培育进度。

## 获取途径与正常存档复核

上述地图缩短操作步骤，不能证明普通存档的每条生存渠道已经被你逐项实际刷到。建议按手册另核对：

- 第 1011–1025 号自然／传说刷新条件、旧版替代地形和究极空间入口是否被整合包禁用。
- 新 Mega Boss 是否出现、同种类多颗石头是否都有掉落、奖励箱是否启用。
- 自然太晶巢穴的比例、读取存档后类型稳定、静止位置和引导线识别。
- 太晶碎片／光盘与高星星晶碎片可重复获得，无极陨星高价原材料能从原重铸渠道获取。
- 普通捕捉、孵化、进化、电脑存取、多人同步不依赖测试地图指令。

如遇问题，记录地图名称、控制台／使用物品、个体形态与携带物、预期与实际结果；附当前补丁版本及日志中的相关异常，便于复现。
